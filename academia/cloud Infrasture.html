Technology & Tools

Explore technologies and tools commonly utilized across cloud-native engineering workflows.

Linux
Open-source operating system standard for hosting server infrastructure and containers.
Docker
Platform used to build, package, and execute lightweight container applications.
Kubernetes
System for automating containerized application deployment, scaling, and management.
Git
Distributed version management system for tracking code and configuration changes.
GitHub
Platform for code hosting, repository management, and continuous integration workflows.
CI/CD
Automation practices for continuously integrating code and delivering application updates.
Cloud
On-demand remote computing resources, virtual networking, and managed services.
Containers
Isolated runtime environments packaging application code along with its dependencies.
