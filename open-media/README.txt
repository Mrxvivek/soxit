OPEN MEDIA — FINAL SINGLE-PAGE WEBSITE

Contents:
- index.html
- assets/images/  (all supplied website images)
- assets/video/bg-video.mp4

How to use:
1. Extract this ZIP.
2. Open index.html in Chrome to preview.
3. Upload the complete folder to Netlify/GitHub or copy it into your main website project.
4. There is no Open Media navigation/menu bar.
5. CSS and JavaScript are embedded inside index.html, so there are no separate CSS/JS files to manage.

Important:
- The contact form is front-end only. Connect it to your backend/form service to actually receive submissions.
- Some supplied stock images contain visible stock/watermark branding. Replace those with licensed clean versions before commercial launch if required.
